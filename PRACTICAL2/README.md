# Practical 2 - Employee Payroll System

## 📌 AIM
Design an **Employee Payroll System** using **Inheritance, Interface & Polymorphism** in C#.

## 📚 Concepts Covered
- **Inheritance** — `FullTimeEmployee` inherits from `Employee`
- **Interface** — `IPayroll` defines the payroll contract
- **Polymorphism** — Interface reference used for runtime method dispatch
- **Encapsulation** — Properties with `private set` protect internal state
