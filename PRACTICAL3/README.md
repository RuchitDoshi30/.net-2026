# Practical 3 - Expense Tracking Module with Exception Handling

## 📌 AIM
Develop an **Expense Tracking Module** in C# showcasing **Exception Handling** (`try`, `catch`, `finally`, `throw`, built-in and user-defined custom exceptions).

## 📚 Concepts Covered
- **`try-catch-finally`** block structure
- **Built-in Exceptions** — `FormatException`, `OverflowException`, `DivideByZeroException`, `ArgumentException`
- **Custom Exceptions** — `InvalidExpenseAmountException`, `BudgetExceededException`
- **Explicit Throwing** — `throw new Exception(...)`
