# Practical 1 - Student Admission Management Module

## 📌 AIM
Develop a **Student Admission Management Module** using Object-Oriented Programming (OOP) concepts in C# including **Classes, Objects, Constructors, Access Modifiers, and Encapsulation**.

## 📚 Concepts Covered
- **Class & Object** — `Student` class and `s1` object instantiation
- **Constructors** — Parameterized constructor initializing fields
- **Access Modifiers** — `private` for data members, `public` for methods
- **Encapsulation** — Controlled access to internal state via methods
